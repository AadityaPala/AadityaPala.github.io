# Aaditya Pala — Portfolio

A responsive, static portfolio website for GitHub Pages. It uses plain HTML, CSS, and JavaScript; there is no build step or package installation.

## Deploy on GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. GitHub Pages will publish the site at `https://aadityapala.github.io/` after the deployment completes.

## Update content

- `index.html` — page content, projects, experience, recommendations, and contact details.
- `assets/styles.css` — layout, responsive styling, and visual theme.
- `assets/script.js` — mobile navigation and reveal-on-scroll behavior.
- `assets/favicon.svg` — browser tab icon.

The portfolio content is based on the résumé and recommendation text supplied for this site. The RAG work in Optimeal is described as a prototype. Project metrics and descriptions should be reviewed and updated as the projects evolve.
